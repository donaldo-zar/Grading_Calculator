Grading Decision Tool

Grade it, or sell it raw?

Search for a card to auto-fill its raw price. The graded price can auto-fill too (from real recent eBay sales) if you add a free PokemonPriceTracker key below — otherwise just enter your own estimate. The math accounts for the ~80% you actually net on a sale and the $150 grading fee.

1. Look up a card

Search pulls live raw card prices from JustTCG. Graded prices, if you've added a free PokemonPriceTracker key, come from that card's recent eBay sales at your chosen grade — otherwise you'll enter that number yourself below.

The formula

Raw Profit: RP = 0.8x
Grading Profit: GP = 0.8y − 150
Grade the card only if GP > RP, which simplifies to y − x > 187.50.

First time using this?
1. Get a free API key at justtcg.com/auth/signup (no credit card needed).
2. Open this file in a text editor, find the line that says PASTE_YOUR_API_KEY_HERE, and put your key between the quotes.
3. Save the file and reopen it in your browser. Search should now work.

Want the graded price to auto-fill too?
Get a second free key (no credit card) at pokemonpricetracker.com/api, then paste it into the other PASTE_YOUR_API_KEY_HERE spot in this file, next to PPT_API_KEY. Without it, everything still works — you'll just keep entering the graded price yourself.

Want it faster, with real graded-price auto-fill?
This page came with a small backend folder (a few files that live on a free server instead of your computer). Deploy it to Vercel, put your two API keys in Vercel's Environment Variables settings instead of in this file, then set USE_BACKEND to true near the PPT_API_KEY line and view this page through your live Vercel URL. See the setup guide for the exact steps.
